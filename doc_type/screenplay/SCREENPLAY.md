# Screenplay

This document type defines the structure and formatting rules used for
screenplay documents in XAL Screenwriter.

## Elements

### Scene Heading

A scene heading must begin with one of the following:

- `EXT.` — Exterior
- `INT.` — Interior
- `#` — Used when neither `EXT.` nor `INT.` applies

### Action

Action may contain any text.

If the first word of an action line is entirely uppercase, the line must
be preceded by `!` to distinguish it from a character element.

### Character

Character names must always be written in uppercase.

### Parenthetical

A parenthetical may appear immediately after a character element.

### Dialogue

Dialogue must immediately follow either:

- a character element, or
- a parenthetical element.
