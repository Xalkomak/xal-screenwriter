# Xalkomak's Screenwriter
Xalkomak's Screenwriter is a free and open-source project for writing scripts. There already are a ton of free and great script writing apps on the internet, which might make one assume this project is redundant. Most of these software have either limited script writing options, limited features which are paywalled, have proprietary file formats which cannot be used anywhere else, or the company might stop supporting said app.

With Xalkomak's Screenwriter, I intend to build a writing tool that can essentially work with any document type the user desires and allow a community to maintain this project.

## Goals:
- Develop an application to write scripts easily
- Load virtually any document type and work away
- Make the application as lightweight and community maintainable as possible
